# CodeAlpha_Stock_Portfolio_Tracker_Python
Stock Portfolio Tracker developed in Python as part of the CodeAlpha Python Programming Internship. Calculates total investment value using predefined stock prices and supports saving portfolio data in TXT/CSV format.


📈 Stock Portfolio Tracker

CodeAlpha Python Programming Internship – Task 2

📌 Project Overview

The Stock Portfolio Tracker is a Python-based application developed as part of the CodeAlpha Python Programming Internship. It allows users to enter stock names and quantities, calculates the total investment value using predefined stock prices, and provides an option to save portfolio details in TXT or CSV format.

✨ Features

- Add stock names and quantities
- Uses a predefined dictionary of stock prices
- Calculates total investment value
- Save portfolio details to TXT or CSV files
- Beginner-friendly and easy to understand

🛠️ Technologies Used

- Python
- Dictionaries
- User Input/Output
- Basic Arithmetic
- File Handling

📂 Project Structure

Stock_Portfolio_Tracker/
│── stock_tracker.py
│── portfolio.txt
│── portfolio.csv
│── README.md

▶️ How to Run

1. Clone the repository.
2. Open the project in VS Code or any Python IDE.
3. Run:

python stock_tracker.py

4. Enter stock names and quantities as prompted.
5. View the total investment value and optionally save the portfolio details.
